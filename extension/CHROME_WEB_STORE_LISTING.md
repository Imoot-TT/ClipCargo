# ClipCargo · Chrome Web Store 上架资料

以下内容用于 Chrome Web Store Developer Dashboard。不要在商店截图、说明或宣传页中使用成人、暴力、受版权保护的影视画面；示例页面请使用自有或公开授权的视频页面。

## 基本资料

- 名称：`ClipCargo - 视频页面收集器`
- 简短说明：`将你主动选择的视频页面链接收进本机 ClipCargo，便于后续整理和处理。`
- 分类：`生产力`
- 语言：`中文（简体）`

## 详细说明

ClipCargo 是 ClipCargo 桌面端的配套浏览器扩展。

当你主动点击工具栏按钮、页面入口或右键菜单时，扩展会将当前页面链接和标题发送到本机运行的 ClipCargo 桌面端，加入收集箱。你可以选择或输入项目名称；桌面端未运行时，链接会暂存在浏览器本地，待桌面端恢复后自动重试。

扩展不会读取浏览历史，不会自行开始下载，也不会把页面内容上传到远程服务器。视频页面入口只用于让你主动选择要收集的页面。

使用前需安装并运行 ClipCargo 桌面端。扩展不会绕过网站登录、付费、DRM 或其他访问控制。

## Privacy 标签页填写建议

单一用途：将用户主动选择的视频页面链接交给本机 ClipCargo 桌面端处理。

用户数据处理声明应如实填写：

- 会处理：用户主动选择的页面 URL、页面标题、用户输入的项目名称；在支持网站上仅在页面内检测视频区域以显示收集入口。
- 不会处理：浏览历史、支付信息、账号密码、通讯录、位置、远程分析数据。
- 数据去向：仅在浏览器本地存储暂存队列，或通过 Native Messaging 发送至同一台设备上的 ClipCargo 桌面端；不发送至远程服务器。
- 隐私政策 URL：必须使用公开 HTTPS 地址，内容可直接采用 `privacy-policy.html` 或 `PRIVACY_POLICY.md`。本地文件路径本身不能填入该字段。

## 权限说明（审核字段可直接使用）

| 权限 | 用途 |
|---|---|
| `activeTab` | 仅在用户主动点击扩展后读取当前标签的 URL 与标题。 |
| `contextMenus` | 提供“收进 ClipCargo”右键菜单。 |
| `storage` | 本地保存最近项目、站点开关和桌面端暂不可用时的待发送链接。 |
| `alarms` | 定期尝试发送本地暂存的链接，不收集额外网页数据。 |
| `scripting` | 用户启用某个站点或要求重新显示入口时，注入本扩展自己的页面入口脚本。 |
| `nativeMessaging` | 与同一设备上的 ClipCargo 桌面端本地通信；不连接远程服务。 |
| 可选网站权限 | 仅在用户明确为某个非内置网站点击“启用”时请求，用来显示页面入口。 |
