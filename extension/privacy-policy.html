ClipCargo 浏览器扩展隐私政策

生效日期：2026-11-21

ClipCargo 浏览器扩展用于把用户主动选择的网页链接发送到同一台设备上的 ClipCargo 桌面端。

我们处理哪些数据

仅在你主动使用“加入收集”功能时，扩展会处理当前页面的 URL、页面标题和你输入或选择的项目名称。为在支持的网站上显示页面入口，扩展会在页面内检测视频区域；不会把页面正文、表单内容、账号密码或媒体文件上传到远程服务器。

当 ClipCargo 桌面端没有运行时，待发送链接会临时保存在浏览器扩展本地存储中；桌面端确认收到后会删除该暂存项。

数据如何使用和共享

上述数据只用于把你选择的页面加入 ClipCargo 桌面的收集。扩展不出售、不出租、不用于广告，也不会把这些数据发送给远程服务器。扩展通过浏览器的 Native Messaging 机制，仅与同一台设备上的 ClipCargo 桌面端本地通信。

数据保留与控制

你可以在扩展弹窗中停用某个网站的页面入口，也可以卸载扩展以清除浏览器扩展本地数据。桌面端已保存的收集记录由桌面端自身的数据管理功能控制。

安全与第三方网站

扩展不会绕过网站的登录、付费、DRM 或其他访问控制。第三方网站的隐私实践由其各自的隐私政策约束。

联系我们

如有隐私或支持问题，请通过 ClipCargo Issues 联系我们。

ClipCargo Browser Extension Privacy Policy

Effective date: November 21, 2026

The ClipCargo browser extension sends web-page links actively selected by users to the ClipCargo desktop app on the same device.

Data We Process

Only when you use the “Collect to ClipCargo” feature, the extension processes the current page URL, page title, and the project name you enter or select. To show an on-page action on supported sites, the extension detects video areas in the page. It does not upload page text, form content, account credentials, or media files to remote servers.

If the ClipCargo desktop app is not running, pending links are temporarily stored in the browser extension’s local storage and are removed after the desktop app confirms receipt.

How Data Is Used and Shared

This data is used only to add pages you select to the ClipCargo desktop inbox. The extension does not sell, rent, advertise with, or send this data to remote servers. It uses the browser’s Native Messaging mechanism only to communicate locally with the ClipCargo desktop app on the same device.

Retention and Control

You can disable the on-page action for a site in the extension popup or uninstall the extension to clear browser-extension local data. Records already saved by the desktop app are managed by the desktop app’s own data-management controls.

Security and Third-Party Websites

The extension does not bypass sign-in, payment, DRM, or other access controls. Third-party websites are governed by their own privacy policies.

Contact

For privacy or support requests, contact us through ClipCargo Issues.
