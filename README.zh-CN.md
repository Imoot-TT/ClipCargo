## 下载

[下载 ClipCargo 0.1.1 Windows x64 安装程序](https://github.com/Imoot-TT/ClipCargo/releases/tag/v0.1.1)

Chrome 扩展会在审核完成后通过 Chrome 应用商店安装。Release 中的 ZIP 是提交商店审核的上传包，不是普通用户的安装文件。

## 功能

- 仅在你主动操作时收集网页视频页面。
- 通过 Chrome 扩展把页面链接发送到同一设备上的 ClipCargo。
- 按项目归类，在本地管理收集箱。
- 在桌面端下载、处理、整理和播放已收集的素材。
- 桌面端未运行时，扩展仅在本地暂存，确认送达后自动清除。

## 隐私

浏览器扩展只处理你主动收集页面的 URL、标题和项目名称，仅与同一设备上的 ClipCargo 本地通信；不会向远程服务器上传媒体文件或页面内容。完整内容见[隐私政策](extension/PRIVACY_POLICY.md)。

## 独立产品

ClipCargo 是独立产品，与 Basic、Quick 或其他仓库没有产品、安装包或数据依赖关系。
