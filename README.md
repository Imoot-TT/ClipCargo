# ClipCargo

ClipCargo 是一款独立的桌面收集工具：把你主动选择的视频页面链接收进桌面端，再集中处理、下载、整理和播放素材。

## 下载

- **Windows 安装程序**：前往 [Releases](https://github.com/Imoot-TT/ClipCargo/releases/latest) 下载最新的 `.exe` 安装包。
- **Chrome 扩展**：正式版将通过 Chrome 应用商店提供；商店审核期间，请仅使用发布说明中提供的测试方式。

## 使用方式

1. 安装并启动 ClipCargo。
2. 在浏览器中打开需要收集的视频页面。
3. 使用 ClipCargo 浏览器扩展或桌面端“添加链接”把页面加入收件箱。
4. 在桌面端选择项目，完成下载、处理和素材管理。

## 隐私

浏览器扩展只处理你主动收集的页面 URL、标题和项目名称，并仅与同一台设备上的 ClipCargo 桌面端通信。完整说明见 [隐私政策](extension/PRIVACY_POLICY.md)。

## 产品独立性

ClipCargo 是独立产品，与 Basic、Quick 及其他仓库没有产品、安装包或数据上的依赖关系。

## English

ClipCargo is a standalone desktop collector for web pages you explicitly choose. Collect a video page from the browser, then organize, download, process, and play the resulting media in the desktop app.

Download the latest Windows installer from [Releases](https://github.com/Imoot-TT/ClipCargo/releases/latest). The browser extension will be installed from the Chrome Web Store when its review is complete.
