# Security policy

Please do not report security issues in public GitHub issues. Send a private report to the repository maintainer through GitHub Security Advisories, including the affected version, reproduction steps, and a minimal proof of impact.

Remove personal URLs, browser profiles, cookies, access tokens, downloaded media, and local paths from the report. ClipCargo is designed to keep media and extension bridge traffic on the local machine; reports involving unexpected network transfer should include the smallest reproducible trace possible.
