# ClipCargo 更新记录

## v0.2.0

### 桌面端 2.0 界面与交互升级

- 全新三段式桌面工作站布局（`1060×680` 默认窗口、集成式标题栏、居中 `Ctrl+K` 全局命令面板、左侧项目工作区树与底部实时任务胶囊）。
- 精简主导航为 `收集箱 / 素材库 / 任务队列`（+ 设置），预览与 FFmpeg 快捷截取/转码（Studio）改为从素材库按需进入，定位更聚焦。
- 收集箱与素材库全面改为右侧全高贴边上下文检视器，消灭旧版阻塞式模态弹窗；支持多选单行批量操作、内联修改保存与安全移除确认。
- 任务队列重构为紧凑单行历史卡片与内联提示，四阶段步进条仅在进行中下载任务展示；右上角轻量主题适配通知（Toast）。
- 全新「胶卷收纳小货箱」品牌图标，同步更新桌面端、Windows 安装包与 Chrome 扩展图标。

### 剪映专业版与 Chrome 扩展升级

- 修复剪映专业版 / CapCut 导入假成功问题，改用 Windows 文件导入弹窗流并校验 `#32770` 对话框真实弹出，未打开草稿时如实提示。
- 全新纵向窄款 `236px` Chrome 扩展弹窗（浅/深色自适应），支持单行标题省略、可选可输入项目分类与快捷胶囊、「收入素材箱」专业文案、页面浮标开关及可折叠「最近收集」抽屉。
- 修复扩展重载后旧页面脚本触发的 `chrome-extension://` 无效资源报错。

## v0.1.7

### 界面与交互

- 统一主导航和设置分类的位置，保持左侧布局。
- 历史记录支持清除显示记录，长标题和次要信息改为悬停查看。
- 素材库支持多选和批量“导入剪辑”，移除素材时明确区分“从库移出”和“删除文件到回收站”。
- 深色主题同步 Windows 标题栏颜色。
- 浏览器扩展检测只保留一个进行中的状态反馈。
- 版本页增加 GitHub 公开版本自检，网络错误不再直接展示底层错误文本。

### 剪辑软件导入

- ClipCargo 不再依赖 Concat 的 MCP 或“自动化”监听器。
- 剪映使用 `-open-file=<path>`，CapCut 使用本地文件参数，Concat 使用正常的文件导入窗口。
- 设置页支持自动选择和已检测到的剪辑软件目标。

### 工程与发布

- 更新桌面端、扩展和 Rust 包版本到 `0.1.7`。
- 增加 Windows 标题栏主题权限和 GitHub 更新请求的系统代理支持。
- 更新许可证清单、扩展说明、静态检查和 UI 测试桩。

### 验证

- `npm run check`
- `npm run licenses`
- `npm run build`
- 已启动 `src-tauri/target/release/clipcargo.exe`，确认版本页显示 `0.1.7`、深色标题栏、版本自检和单一扩展检测状态。
