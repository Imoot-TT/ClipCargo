# ClipCargo 更新记录

## v0.1.7

### 界面与交互

- 统一主导航和设置分类的位置，保持左侧布局。
- 历史记录支持清除显示记录，长标题和次要信息改为悬停查看。
- 素材库支持多选和批量“导入剪辑”，移除素材时明确区分“从库移出”和“删除文件到回收站”。
- 深色主题同步 Windows 标题栏颜色。
- 浏览器扩展检测只保留一个进行中的状态反馈。
- 版本页增加 GitHub 公开版本自检，网络错误不再直接展示底层错误文本。

### 剪辑软件导入

- ClipCargo 不再依赖 Concat 的 MCP 或“自动化”监听器。
- 剪映使用 `-open-file=<path>`，CapCut 使用本地文件参数，Concat 使用正常的文件导入窗口。
- 设置页支持自动选择和已检测到的剪辑软件目标。

### 工程与发布

- 更新桌面端、扩展和 Rust 包版本到 `0.1.7`。
- 增加 Windows 标题栏主题权限和 GitHub 更新请求的系统代理支持。
- 更新许可证清单、扩展说明、静态检查和 UI 测试桩。

### 验证

- `npm run check`
- `npm run licenses`
- `npm run build`
- 已启动 `src-tauri/target/release/clipcargo.exe`，确认版本页显示 `0.1.7`、深色标题栏、版本自检和单一扩展检测状态。
